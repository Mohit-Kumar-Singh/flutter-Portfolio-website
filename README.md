# Mohit Kumar Singh — Portfolio

Live: https://mohit-portfolio-five-tau.vercel.app

A minimal portfolio with Framer-style motion, built with Next.js 16, [Motion](https://motion.dev) and [Lenis](https://lenis.darkroom.engineering).

## Edit content

All copy, projects and links live in [`lib/content.ts`](lib/content.ts). Images go in `public/images/`.

## Develop

```bash
npm install
npm run dev
```

Pushing to `main` deploys to production on Vercel automatically.

The previous Flutter portfolio is preserved on the `flutter-legacy` and `flutter-legacy-main` branches.
